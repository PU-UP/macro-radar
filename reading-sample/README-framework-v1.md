# 宏观观察阅读样稿

## 交付范围

`index.html` 为自包含独立阅读页；无外部字体、依赖、网络请求或实时数据接口。原版文件保持不变，从样稿页底部可返回原版。删除整个 `reading-sample` 子目录即可撤回样稿。

主题：成本变化如何通过定价权与需求传导到行业利润。

- 首屏为主题问题与待验证判断，没有任务管理控件。
- 顺序为发生什么 → 为什么重要 → 行业联系 → 支持与反证 → 按需展开证据。
- 传导图明确为机制示意；没有模拟时间序列、未核验实际数值或无规则仪表评分。
- 三个企业类型按钮更新对应的条件、证据需求和反证。
- 原生 details 展开来源与方法；窄屏布局、焦点可见和减弱动态规则已定义。

## 等待 Olive 的内容

先交付此主题的一小组证据，避免把全部宏观领域塞回首屏：

1. **观察结论**：一句可由数据支持的当期判断；地区、行业范围和截止日；事实、解释与推演分别标识。
2. **价格序列**：同一行业可比较的投入成本与售价序列；数值、单位、频率、同比/环比、季调与基期、统计期、发布日期、原始来源链接、访问/核验日期、修订情况与缺失值。无法比较时说明限制，不硬算价差。
3. **经营证据**：匹配范围的订单/销量、利润率或现金流；明确行业整体还是企业样本，以及样本选择依据。
4. **行业联系**：最多三类企业，各自的受影响机制、必要条件、例外和反证；资产层面区分经营受益与市场已计价。
5. **下一次验证**：待发布数据或报告、可确认的发布日期、哪些变化将增强/削弱判断。阈值仅在有合理依据时提供。

每条证据应有 stable id、核验状态、支持的判断 id，便于正文与展开证据对应。现有样稿内容只作条件推演，不承诺任何当期行业机会。

## 验证边界

仅做源码与静态检查、脚本语法及隔离的行业切换逻辑检查。未完成浏览器视觉验收或真实键盘/触屏验收。此前浏览器安全策略拒绝 file URL，并明确禁止间接绕过；未新建服务器、未替换浏览器表面、未公开发布。
